# codingan-apk-tiket-bus
 langkah-langkah seseorang untuk mengakses codingan aplikasi pemesanan tiket bus adalah sebagai berikut:

1. **Membuka link repository GitHub**
   Pengguna terlebih dahulu membuka alamat repository, yaitu `https://github.com/shalfianf-glitch/codingan-apk-tiket-bus`, sehingga akan muncul halaman utama repository seperti pada gambar.

2. **Melihat daftar file proyek**
   Setelah halaman terbuka, pengguna dapat melihat berbagai file dan folder yang terdapat di dalam repository, seperti **AndroidManifest.xml**, **README.md**, **build.gradle.kts**, **bus_android.iml**, dan **settings.gradle.kts**. File-file tersebut merupakan bagian dari source code aplikasi Android.

3. **Membaca file README**
   Pada bagian bawah halaman terdapat menu **README**, yang berisi informasi atau dokumentasi mengenai proyek. Pengguna dapat membaca penjelasan terkait aplikasi sebelum menggunakan atau mengembangkan source code.

4. **Mengunduh source code**
   Untuk mendapatkan seluruh kode program, pengguna dapat menekan tombol **Code** berwarna hijau yang berada di bagian atas daftar file. Selanjutnya pilih **Download ZIP** untuk mengunduh proyek dalam bentuk file ZIP atau salin URL repository jika ingin menggunakan perintah **Git Clone**.

5. **Mengekstrak file hasil unduhan**
   Apabila memilih **Download ZIP**, pengguna harus mengekstrak file tersebut hingga seluruh folder dan file proyek dapat diakses di komputer.

6. **Membuka proyek pada Android Studio**
   Setelah file berhasil diekstrak, pengguna membuka aplikasi **Android Studio**, kemudian memilih menu **Open** dan memilih folder proyek yang telah diunduh. Android Studio akan melakukan proses sinkronisasi (Gradle Sync) sehingga seluruh source code dapat dibuka dan dijalankan.

7. **Menjalankan aplikasi**
   Setelah proses sinkronisasi selesai, pengguna dapat menjalankan aplikasi dengan menekan tombol **Run** dan memilih emulator atau perangkat Android yang terhubung. Dengan demikian, aplikasi pemesanan tiket bus dapat diuji dan dikembangkan lebih lanjut.

**Kesimpulan:**
akses terhadap codingan dilakukan dengan membuka repository GitHub, melihat isi file proyek, mengunduh source code melalui tombol **Code**, kemudian membuka proyek di **Android Studio** untuk dijalankan atau dikembangkan sesuai kebutuhan.
